# Slash Commands and Bot Buttons

Bots in a space can offer **slash commands**, and put **buttons** and
**menus** on their messages.

## Using a Command

1. Type `/` in the message box of a space channel. The commands of the bots in
   that space appear; keep typing to narrow the list.
2. Pick one. Its options appear in the message box — text fields, lists of
   choices, on/off switches, or pickers for a member, a channel or a role.
3. Fill in the required ones and press **Enter** (or the send button).
   **Esc** cancels.

Shortcut: type the whole command, like `/play never gonna give you up`, and
press Enter — when the text fills its first option, it runs straight away.

While the bot works, the box shows "Sending /play…". The bot's answer shows
who used the command ("Ada used /play"). If the bot is preparing a longer
answer, its message says "is thinking…" until it's ready. If it doesn't answer
within a few seconds, the box says the application did not respond.

Some answers are only for you: they say **Only you can see this**, disappear
when you reload, and **Dismiss message** removes them right away.

## Buttons and Menus

Click a bot's button or pick from its menu to act on that message (pause a
song, choose an option…). The control spins until the bot answers; "This
interaction failed" means it didn't. Link buttons open a web page, after
confirmation.
